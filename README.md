# Keeprs

A markdown editor and Excalidraw-powered notebook for capturing and organizing your notes — self-hosted, private, yours forever.

## What is Keeprs?

Keeprs is a desktop note-taking app built on markdown and Excalidraw. Write notes, sketch diagrams, and keep everything organized in a local SQLite database. No cloud sync, no accounts, no telemetry — your data stays on your machine.

Built with Rust, SQLite, HTMX, Stimulus, and CodeMirror 6.
